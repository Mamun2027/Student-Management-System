# Student Management System

A simple Java-based Student Management System designed to manage student information and course details. This project demonstrates the use of Object-Oriented Programming (OOP) concepts in Java.

## Project Overview

The Student Management System is a console-based application developed to organize and manage student records efficiently. It provides a basic structure for handling student information and course-related details.

## Features

- Manage student information.
- Store and organize student records.
- Manage course information.
- Use object-oriented programming principles.
- Organize the application into separate Java classes.

## Technologies Used

- **Programming Language:** Java
- **Development Environment:** Visual Studio Code
- **Version Control:** Git
- **Repository Hosting:** GitHub
